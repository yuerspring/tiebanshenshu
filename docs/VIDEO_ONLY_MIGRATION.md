1. 太玄、先后天卦数独立保存，互卦按二三四爻/三四五爻推导，无默认乾卦。
2. 乾宫父亲生肖基条：鼠9003，之后每生肖加50，至猪9553。坤宫母亲生肖基条：鼠9605，之后加50，至猪10155。视频父鼠9003、母牛9655与公开表一致。
3. 依视频给出每个父母基条加0、10、20、30、40的核对候选，但不根据这些数字猜出完整干支年份。
4. 坤集编码支持“月”“支”均为0，并支持五字符编码，例如甲月月月壬=10005。五位编码仅用于解读表，不擅自接入只演示四位分组的化卦步骤。
5. 论命基数逐加96，超过13000减12000；数字返回起点则结束。周期12000/gcd(12000,96)=125条，并非遍历12000条。不给寿终条文自动设真实年龄。

## 《皇极经世书》不是当前缺失条文库的证据

本次读取维护者上传的 EPUB：邵雍撰、王鹤鸣与殷子和整理，九州出版社2012年4月第一版、2016年3月第三次印刷，ISBN978-7-5108-1435-8。

解出71个HTML文件、371781字符正文；目录为观物篇、观物外篇及皇极经世机要图、律吕声音机要图等。正文未检索到“9467”“兄弟四人”“我居次”“乾坤甲流度”“考刻”“条文”。这是正文与目录核对，不声称全部76张插图已逐图核验。

因此，目前没有证据将它认定为视频使用的12000条编号断语底本；不能将《皇极经世书》《皇极天书》《皇极数》仅因书名相近当成同一本。不会用其元会运世图直接替换视频考刻表。

## 视频与现有条文的具体冲突

视频09:40附近：白板推导9467，口述“兄弟四人，我居次”。现有List.csv与公开条文对照页中，这句在9466；9467为“己酉之年，宴饮鹰扬”。这可能是口误、抄录差异或底本不同，现有证据不足以决定原因。不能把所有条号统一减1，也不能仅覆盖9467掩盖冲突。

## 还不能宣称“完整按视频自动测算”的地方

- 后卦“时上日下、配后天数”的取余边界与五数处理没有完整示例，不借用其他版本的减10或寄坤规则。
- 考刻条号、化卦后论命基数、本命卦数三者不能未经证据直接等同；前后卦仍要求有依据的本命卦数输入。
- 天干合化完整月令条件未全部公开，不把其他流派的合化条件填成视频原规则。
- 1327候选的越界不可直接套用96轮转段规则。

视频优先意味着保留它实际公开的算法和缺口，不能为了生成“完整结果”编造未展示的规则。出生分钟不直接决定全部条号，视频以候选与事实核验推进，没有“每一分钟必须得到不同结果”的公式。
