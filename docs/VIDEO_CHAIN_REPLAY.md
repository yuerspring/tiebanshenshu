# 按视频的例子接续全部可计算步骤

维护者要求先对逻辑和数值，条文版本差异稍后处理。本次修正此前“条文尚未匹配，所以后续也不能演算”的产品限制。所有步骤均可在空条文库运行，不需要条文匹配才能继续算数。

## 同一例子的计算链

教学四柱：乙巳、辛巳、甲申、丙子。父鼠流度基条9003作为本次所选演算输入，运柱壬午。

| 顺序 | 视频口述、白板或叠加操作文字 | 程序推导 |
|---|---|---|
| 初候选 | 02:58四柱太玄数，除时支序数；05:50余数说明卡 | (8+4)+(7+4)+(9+7)+(7+9)=55，子序数1，余0暂作一刻 |
| 第二种考刻 | 07–10分月上年下、固定加6、互卦组合 | 月11除8余3离；年12除8余4震；互坎6/艮7；(3+6)×1000+4×100+6×10+7=9467 |
| 第三种考刻 | 11–15分父母生肖流度、按年验条 | 父鼠9003；母牛9655；各列基条、+10、+20、+30、+40。本次选择9003继续算数，不冒充现实验条已完成 |
| 四柱八条 | 15:26天干/地支配卦；20:00爻位配数；23:20上下卦合计 | 加则2381、4381、6382、8389；干支化数3345、3945、3942、4226 |
| 所选基数化卦 | 24:50–26:15：前两位和作上卦，后两位和作下卦；再八卦加则作为推命基数 | 9003：9+0−8=1坎；0+3=3震；阴阳分别由上而下配30/60/90…，合390；1×1000+390−3=1387 |
| 论命条号 | 26:20–27:10：逐加96，超13000减12000 | 1387、1483、1579……至回到起点，共125个不同条号 |
| 视频另设的假定 | 26:20附近“假设配到3456” | 3456是讲解96递加的假定值，不是9003经过加则的实算结果；3456、3552、3648……可独立复算 |
| 流年分支 | 29:05文字卡、30:40干支表、31:07白板 | 月日時年为辛甲丙乙→6464；运壬3、午2/7；6464+3+2+7=6476 |

## 修正的两处流程断点

1. 25:50–26:15口述已定义化卦加则所得数为后续推命基数。此前把前后卦的本命卦数留作必需的独立手填项，导致流程断开。本次按上下文将1387传到后续步骤，同时保留手动覆盖入口供其他明确底数复算。这个变量衔接是根据相邻步骤推导，并非视频白板明写“9003→1387→4854”。
2. 31:50明确前后卦继续用此前讲过的太玄配数，33:15文字卡给出时上日下、后天配数和组合加本命卦数。本次不再把全部后卦分支直接置为空，而是承接除8方法实际计算，后天数表遇5时才局部停在中五寄卦处。后卦8831及以上四条是按这些规则推导的程序结果，视频没有把它们逐项写成答案，不能标为视频金标准答案。

## 演算与验条分开

`basis_number`允许选择基数直接演算；`input_fact_verified=false`明确它未经过现实事实验条。原`confirmed_number`语义仍保留事实核验声明。两种输入走同一算术方法。修改或清空条文库不会改变任何中间数或最终条号。

默认教学按钮同时载入四柱、9003和壬午，一次点击便可查看整条计算链。旧版并未缺失的叠加表和操作文字见 [插表逐项清单](VIDEO_INSERT_TABLES.md)。

余9→下一时辰一刻的操作文字按八刻连续编号推广为余10→下一时辰二刻、余11→三刻，结果中保留时辰偏移；这是同一编号规则的推广。96序列的条号按1001–13000轮转并保留原算术数，不将条号范围问题误报成算法不能计算。

尚需单独补充的是后天中五寄卦及未全部演示的合化成立条件；它们不阻断视频当前示例的未合化计算路径。

验证：71项测试，包括空条文库完整跑通本例、手填覆盖、未验条直接演算、中五仅暂停后卦分支、96边界与余数进刻。
