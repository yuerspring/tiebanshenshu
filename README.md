## 项目概述

铁板神数以人的出生年月日时（四柱八字）为输入，通过数理变换得到若干数字，最终映射至12000条预定义条文（类似签文）。本系统实现了完整的铁板神数算法体系，包括：

- **太玄数转换**：将天干地支转换为数值
- **基础数计算**：由四柱太玄数累加得到初始整数
- **考时定刻**：利用已知的六亲事实调整基础数，精确识别个体
- **秘数运算**：针对不同命理事项的偏移量计算
- **条文映射**：从核心数推算出对应条文编号

## 核心算法流程

### Step 1: 计算先天命数

```
先天命数 = 农历月份值 + 3 - 时支值
若结果 ≤ 0，则加 12
```

- 农历月份值：从 14-1.csv 获取
- 时支值：从 14-2.csv 获取

### Step 2: 计算五音命数

- 根据年干分组（甲己、乙庚、丙辛、丁壬、戊癸）和先天命数，从 14-3.csv 获取五音
- 五音（宫、商、角、徵、羽）对应数值从 14-4.csv 获取

### Step 3: 计算日命数和时运数

- 日命数：根据日柱纳音和时干，从 14-5.csv 获取
- 时运数：根据时柱纳音，从 14-6.csv 获取

### Step 4: 确定刻别（初刻/正刻）

根据日命数+时运数的和值、性别和年干阴阳判断：
- 阳男阴女：和>6→初刻，和≤6→正刻
- 阴男阳女：和>6→正刻，和≤6→初刻

### Step 5: 计算本命数

```
当 日命数+时运数 ≤ 6 时:
    本命数 = (五音命数 × 5 + 日命数 + 时运数 - 1) × 30 + 农历出生日
当 日命数+时运数 > 6 时:
    本命数 = (五音命数 × 5 + 日命数 + 时运数 - 6) × 30 + 农历出生日
```

### Step 6: 查找卦名

根据刻别和本命数，从 14-9.csv（完整版）查找对应的十二辟卦；若未找到，则降级使用 14-8.csv（仅按本命数查找）。

### Step 7: 计算后天命数

```
后天命数 = (先天命数 + 本命数) % 8
若余数为 0，则取 8
```

### Step 8: 计算流年条文（含校正与断语）

遍历 1-108 岁，计算每岁的：
1. 流年干支
2. 流年天四声（从 14-11-2.csv 获取）
3. 流年标记（从 14-12.csv 获取，依赖流年地支和后天命数）
4. 流年字母（从 14-13.csv 获取，依赖刻别、岁数奇偶性、四声、标记）
5. 原始条文数（从 14-14.csv 获取，依赖字母和岁数，基数+加数）
6. 条文校正：
   - 若年龄在 1-10 或 81-108 岁：校正数 = 原始校正数 + 2（若>6则减6）
   - 否则：校正数 = 原始校正数 + 3（若>20则减20）
7. 断语查询：从 List.csv 根据条文数（原始和校正后）获取断语内容和对应年龄

## 推算流程详解

### 上篇：本命条文部分

推算某人的本命条文所必须的数据有：
⑴ 求测人的生辰八字
⑵ 求测人出生的农历月份
⑶ 求测人出生的农历日子
⑷ 求测人的求测时辰

有了以上四个数据，就可以为求测人推算本命条文了，其演算流程如下：

#### 一、求先天命数

㈠ 求"月命数"和"时命数"
1. 方法：将生辰中的农历出生月份和时柱地支按照"月份配数表"（附表14－1）、"时支配数表"（附表14－2）转化为数字，分别即是月命数和时命数。（如果逢闰月，须按下个月计算）。
2. 举例：
   - 农历正月生人，时支为"戌"→ 月命数=1，时命数=11。
   - 农历闰八月生人，时支为"申"→ 按九月计，月命数=9，时命数=9。

㈡ 求先天命数
1. 方法：先天命数 = 月命数 + 3 - 时命数。
2. 说明：若结果小于0，则加12；若大于12，则减12（通常只在负值时处理）。
   - 例：月命数=1，时命数=11 → 1+3-11=-7，+12=5，先天命数=5。

#### 二、求五音命数
1. 方法：由先天命数配合年柱天干，查"起五音表"（附表14－3）得五音；再查"五音配数表"（附表14－4）得五音命数。
2. 例：年干乙，先天命数=6 → 五音为"商"→ 配数=4，五音命数=4。

#### 三、起"日命数"和"时运数"
㈠ 起日命数：将日柱纳音五行配合求测时辰天干，查"起日命数表"（附表14－5）。
㈡ 起时运数：由求测时辰的纳音五行，查"起时运数表"（附表14－6）。

#### 四、考刻
规则：
⑴ 阳男阴女，日命数+时运数 > 6 → 初刻生人。
⑵ 阳男阴女，日命数+时运数 ≤ 6 → 正刻生人。
⑶ 阴男阳女，日命数+时运数 > 6 → 正刻生人。
⑷ 阴男阳女，日命数+时运数 ≤ 6 → 初刻生人。
（可查附表14－7）

#### 五、求本命数
- 当日命数+时运数 ≤ 6 时：本命数 = (五音命数×5 + 日命数 + 时运数 - 1)×30 + 农历出生日
- 当日命数+时运数 > 6 时：本命数 = (五音命数×5 + 日命数 + 时运数 - 6)×30 + 农历出生日

#### 六、求本命条文
㈠ 确定本命数对应的十二辟卦：
- 初刻生人查"初刻本命十二辟卦表"（附表14－8）
- 正刻生人查"正刻本命十二辟卦表"（附表14－9）
（各表分上中下，对应本命数范围181～430、431～680、681～930）

㈡ 求本命条文：
1. 根据辟卦选取对应的"本命条文秘数表"（附表14－10，共12张）。
2. 按先天命数所在行（区分正刻/初刻），将"十二辟卦"后的数字、"序数"及预测项目下的数字相加，即得各条文号码。
3. 预测项目中如有"×"表示无条文可查；若有多项数据则得出多条条文。

---

#### 下篇：流年条文部分

所需数据：出生年柱、先天命数、本命数、考刻结果（正/初刻）。

#### 一、求流年天四声
1. 根据先天命数选取对应的"先天命数运限表"（附表14－11，共12个）。
2. 按出生年支、年干及男/女命，从表中"起流年天四声顺序"得一组12个数字（四、五、六、七），每12年循环一次，配入各流年岁数。

#### 二、求流年字母
㈠ 求后天命数：后天命数 = (先天命数 + 本命数) ÷ 8 的余数。
㈡ 求流年标记：由流年地支配合后天命数，查"流年标记表"（附表14－12）。
㈢ 求流年字母：
- 初刻生人：奇数岁用表㈠，偶数岁用表㈡。
- 正刻生人：奇数岁用表㈢，偶数岁用表㈣。
（查附表14－13，由天四声和流年标记交叉得字母）

#### 三、求流年条文
1. 查"流年条文秘数表"（附表14－14），将流年岁数和流年字母对应的两个数据相加，即得条文号码。
2. 条文校正：
   - 1～10岁及81～108岁：校正数加2（若>6则减6），换新校正数对应的字母重新求条文。
   - 其他岁数：校正数加3（若>20则减20），换新字母。
   - 可进行第二次校正，一般一至两次即可。

## 扩展算法模块

### 皇极玄机总卦

基于四柱八字和动爻信息计算的卦象，用于后续的条文检索和六亲生肖推算。

**算法步骤：**
1. 六十甲子天地立成定数：阳加策以四柱地支定之，老少等，老者多加720，少者多加360
2. 年除数：甲乙减11，丙丁减3，戊己减11，庚辛减4，壬癸减9
3. 动卦策数：乾126、兑132、离138、震144、巽150、坎156、艮162、坤168
4. 总策数 = 四柱定数 + 老少等 + 动卦策数 - 年除数
5. 皇极卦：千百加得卦，个十加得卦

### 六亲生肖范围

通过太玄数计算六亲生肖范围：
- 父母生肖：天元数 + 地元数 - 10，余数对应生肖范围
- 兄弟生肖：月干太玄数 + 月支太玄数 - 10，余数对应生肖范围
- 妻财生肖：日支太玄数 + 时支太玄数 - 10，余数对应生肖范围

### 人元数计算

根据天元数、地元数、世爻五行数、动爻五行数计算人元数：

```python
A = 天元数 + 地元数
B = 世爻五行数 + 动爻五行数
D = 生日

if A < 7 and B > 6:
    C = 30 * (5 * A + B - 11) + D
elif A > 6 and B < 7:
    C = 30 * (5 * A + B - 31) + D
elif A < 7 and B < 7:
    C = 30 * (5 * A + B - 6) + D
elif A > 6 and B > 6:
    C = 30 * (5 * A + B - 36) + D
```

### 六亲条文命数

```
父亲、大姐命数 = 先天命数 + 1
母亲、大哥命数 = 先天命数 - 1
夫妻、二哥命数 = 先天命数 - 2
子女、三哥命数 = 先天命数 - 3
四哥命数 = 先天命数 - 4
五哥命数 = 先天命数 - 5
二姐命数 = 先天命数 + 2
三姐命数 = 先天命数 + 3
四姐命数 = 先天命数 + 4
五姐命数 = 先天命数 + 5
```

## 考刻取数法

### 先天基本卦考六亲

1. 排四柱，配上太玄数
2. 以先天基本卦考六亲：阳男阴女年干加年支为上卦，月干加月支为下卦；阴男阳女反之
3. 计算互卦：基本卦的上卦为千位数，下卦为百位数，互出的卦上卦为十位数，下卦为个位数
4. 若条文不符合实际情况，则以基本卦初爻为动爻变出一卦，重新计算
5. 加减推断：基础数 ± 48×2/4/8/16

### 后天运程取数法

1. 日柱太玄和减10为后天上卦
2. 时柱太玄和减10为后天下卦
3. 上下卦合得出后天基本卦，再求出互卦
4. 基本卦和互卦取数均为后天数
5. 加减推断：基础数 ± 48×2/4/8/16

## 心易派兄弟姐妹数计算

1. 天干取数：甲1、乙2、丙3、丁4、戊5、己6、庚7、辛8、壬9、癸0
2. 立卦：年干+月干为上卦，日干+时干为下卦
3. 变卦取数：上卦百位下卦零
4. 六亲用神数：父母爻（天干值-地支值）×10
5. 条文数计算：基数（父亲1000/母亲2000）+变卦数+用神数

## 八刻分命详解

铁板神数批算命运是把四柱八字每个时辰分成八刻，每刻十五分，每分六十秒进行卦气详解。依据此法可批算相同八字产生的不同命运结果。

**程序如下：**
1. 依四柱求得河洛先天命卦
2. 由先天命卦依据阴阳顺逆求得八刻命卦
3. 由每刻命卦求得十五分卦
4. 由每分卦求得六十秒卦
5. 将每个卦用纳甲秘法求得百位个位数序
6. 每卦纳支求得十位数序
7. 由时辰求得千位
8. 四位相加便求得铁板条文数序

**关键口诀：**
- 八卦纳甲口诀：乾纳甲壬坤乙癸...
- 八卦纳支口诀：乾纳子寅辰午申戍...
- 地支藏干口诀：子藏癸水在其中...
- 纳甲数序：甲一丙二戊三庚四壬五乙六丁七己八辛九癸零
- 阴阳顺逆口诀：阳男阴女顺行；阴男阳女逆推
- 先天八卦数序：乾1兑2离3震4巽5坎6艮7坤8
- 后天八卦数序：坎1坤2震3巽4中5乾6兑7艮8离9

## 考刻分秘法

### 心易派考刻分步骤

**（1）先看父亲的刻：**
- 申子辰为7刻、11刻、3刻
- 巳酉醜为4刻、8刻、12刻
- 寅午戌为1刻、5刻、9刻
- 亥卯未为10刻、2刻、6刻

如父母爻酉金，归类在巳酉醜的4刻、8刻、12刻当中，考父亲生肖就在这三刻当中查条文。

**（2）再看母亲的分：**
- 申子辰为7分、11分、3分
- 巳酉醜为4分、8分、12分
- 寅午戌为1分、5分、9分
- 亥卯未为10分、2分、6分

如父母爻未土，归类在亥卯未中为10分、2分、6分，考母亲生肖就在这三分当中查条文。

**（3）秒的求法：**
命卦中纳入的干支太玄数，直接除以49，求余数。如父母爻乙未，纳88，用88/49得1余39，既是用39秒的数。如果父亲数不合则用秒数加减7的倍数求得准确的父亲兄弟数后，如果母亲数不合再用所得秒数加一的倍数，便求得母亲的姐妹数。

## 重要修改记录

### 1. 算法修正：本命数计算公式
**原错误**：使用固定公式 `(五音命数×5+日命数+时运数-1)×30+农历出生日`
**修正**：根据日命数+时运数之和选择公式：
- 和≤6：减1
- 和>6：减6

### 2. 算法修正：考刻逻辑
**原错误**：使用出生时间分钟数判断刻别
**修正**：根据日命数+时运数之和、性别和年干阴阳判断

### 3. 算法修正：流年天四声偏移量
**原错误**：使用 `(13 - start) % 12` 计算偏移量，且错误地使用了起始数进行偏移
**修正**：移除起始数偏移逻辑，直接使用 14-11-2.csv 中的原始序列

### 4. 数据修正：14-11-1.csv
**原错误**：亥卯未组男性起始数为12
**修正**：更正为2，与文档实例一致

### 5. 数据修正：14-11-2.csv
**原错误**：先天命数11、天干甲的序列数据错误
**修正**：更正为正确序列（五,七,四,七,七,四,五,四,六,五,六,六）

**原错误**：先天命数2、天干辛的序列数据错误
**修正**：更正为正确序列（四,四,四,七,四,四,七,五,五,六,七,六）

### 6. 数据修正：14-13.csv
**原错误**：初刻+奇数+四+石的字母为"福"
**修正**：更正为"神"，与修正版文档一致

## 推算实例

### 实例一：男命 1951年农历九月十四日酉时

**四柱**：辛卯 戊戌 丁亥 己酉
**求测时辰**：丙辰时

**【求本命条文】**

1. **先天命数**  
   月命数=9（九月），时命数=10（酉） → 9+3-10=2。

2. **五音命数**  
   先天命数2，年干辛 → 五音为"宫" → 配数5。

3. **日命数与时运数**  
   日柱丁亥纳音土，求测时干丙 → 日命数=2；求测时丙辰纳音土 → 时运数=5。

4. **考刻**  
   日命数+时运数=2+5=7>6，年干辛为阴男 → 符合规则⑶，正刻生人（酉时正刻）。

5. **本命数**  
   五音命数5，日命数2，时运数5，农历十四日 → 和>6，用公式②：  
   (5×5+2+5-6)×30+14 = 26×30+14 = 794。

6. **本命条文**  
   正刻生人，本命数794 → 查正刻本命十二辟卦表得"大壮"卦。  
   取"本命条文秘数表㈣"，正刻先天命数=2所在行数据：  
   十二辟卦大壮+440，序数+430，性格7449和926，才能3829，财运5147，兄弟6444。  
   求和得：  
   - 性格：440+430+7449=8319；440+430+926=1796  
   - 才能：440+430+3829=4699  
   - 财运：440+430+5147=6017  
   - 兄弟：440+430+6444=7314

**【求流年条文】（1～40岁）**

- **流年天四声**：先天命数2 → 取运限表㈡，年支卯，年干辛，男命 → 得一组12个天四声（四四四七四四七五五六七六），循环配入。
- **后天命数**：(2+794)÷8余数4。
- **流年标记**：由地支配合后天命数4查表得。
- **流年字母**：正刻生人，奇数岁用表㈢，偶数岁用表㈣。
- **条文求和**：逐岁查流年条文秘数表相加。

**条文校正**（仅举例）：  
6岁字母"屯"，校正数4+2=6，新字母对应条文 817+7691=8508（符合）。  
7岁字母"尾"，校正数5+2=7→减6=1，新字母条文 992+3696=4688（符合）。  
20岁字母"西"，校正数14+3=17→"龙"，条文 559+6632=7191（符合）。  
33岁字母"离"，校正数15+3=18→"尾"，条文 200+3008=3208（符合）。

### 实例二：男命 1924年农历五月十五日申时

**四柱**：甲子 庚午 乙丑 甲申
**求测时辰**：己巳时

**【求本命条文】**

1. **先天命数**  
   月命数=5（五月），时命数=9（申） → 5+3-9=-1，+12=11。

2. **五音命数**  
   先天命数11，年干甲 → 五音"征" → 配数2。

3. **日命数与时运数**  
   日柱乙丑纳音金，求测时干己 → 日命数=4；求测时己巳纳音木 → 时运数=3。

4. **考刻**  
   和=4+3=7>6，年干甲为阳男 → 规则⑴，初刻生人（申时初刻）。

5. **本命数**  
   (2×5+4+3-6)×30+15 = 11×30+15 = 345。

   泰+430，序数+470，性格8860和453，才能×（无），财运9706，兄弟659。
